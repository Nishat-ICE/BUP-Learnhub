BUP LearnHub - MERN Stack LMS

How to run:

1. Make sure MongoDB is running.
2. Open this folder in VS Code.
3. Open Terminal 1:
   cd backend
   npm install
   npm run dev

4. Open Terminal 2:
   cd frontend
   npm install
   npm run dev

5. Open browser:
   http://localhost:5173

Features:
- Classy professional UI
- Login/Register
- JWT authentication
- Role-based system
- Student, Faculty, Staff, Admin, Authority
- Dashboard
- Courses
- Course enrollment
- Assignments
- Assignment submission
- Announcements
- MongoDB database
- Express API
- React frontend
